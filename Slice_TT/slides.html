Phân tích thị trường & Bài toán thực tế

⚠️ Vấn đề

  • Web bán sách truyền thống tải lại toàn bộ trang khi chuyển đổi — trải nghiệm chậm
  • Người dùng cần tìm kiếm nhanh theo danh mục, khoảng giá, và xem đánh giá trước khi mua
  • Cần tính cá nhân hóa cao và tốc độ truy xuất dữ liệu lớn

✅ Giải pháp BookVerse

  • SPA (Single Page Application) — chuyển trang mượt mà, không reload
  • Tìm kiếm real-time theo tên sách / tác giả, lọc 6 danh mục + khoảng giá
  • Quản trị kho chặt chẽ: giới hạn mua theo tồn kho, tự động cộng lượt bán khi đơn hoàn thành

Thiết kế Cơ sở dữ liệu (ERD)

Users

id, name, email, password, phone, address, role, createdAt

Categories

id, name, description, image

Books

id, title, author, price, originalPrice, categoryId, stock, pages, image, publisher, year, rating, reviews, sold...

Orders

id, userId, items[], totalAmount, shippingFee, paymentMethod, status, createdAt

Mối quan hệ:

  • 1-n: Category → Books (1 danh mục chứa nhiều sách)
  • 1-n: User → Orders (1 user có nhiều đơn)
  • n-n: Order ↔ Books (qua mảng items)
  • categoryId hỗ trợ dạng số và mảng (đa danh mục)

Bảo mật & Tối ưu hệ thống

🔒 Bảo mật

  • Phân quyền qua trường role + isAdmin (Context API)
  • Admin route được bảo vệ — không phải admin → redirect /login
  • Session lưu localStorage, tự khôi phục khi reload
  • Mật khẩu plain text (demo) — Production cần Bcrypt

⚡ Tối ưu

  • React Router chỉ render component khi truy cập route
  • Giỏ hàng + session lưu localStorage — giảm API call
  • CSS Design System dùng biến CSS — dễ thay đổi theme
  • Responsive: Mobile (<768px), Tablet, Desktop (>1024px)
